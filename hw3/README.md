# Трекер книг

Все книги хранятся в `list`, потому что набор записей постоянно меняется: книги добавляются и удаляются, а порядок добавления хочется сохранить.
Одна книга это `tuple` `(id, title, author, year)`, где year это год написания, у записи фиксированная структура и менять ее после создания не нужно, к тому же кортеж можно использовать как ключ или элемент множества.
Для быстрого поиска книги по id используется `dict` `{id: книга}`, так поиск идет за O(1), а не перебором всего списка.
Авторы лежат в `set`, потому что там важна только уникальность, порядок и количество повторов не интересуют.
Списки и множества создаются в `__init__`, а не в аргументах по умолчанию, и наружу `all_books()` отдает копию, чтобы снаружи нельзя было случайно испортить внутренний список.
